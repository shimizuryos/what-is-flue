## Flue とは？

**Flue** は [Astro](https://astro.build/) チームが作っている、TypeScript で AI エージェントを作るためのフレームワークです。React のコンポーネントとフック（`useState` など）に似た書き方で、

- 使う **LLM**（モデル）
- エージェントが使える **ツール・スキル・サブエージェント**
- ファイル操作やコマンド実行のための **サンドボックス**
- 会話をまたいで残る **状態（ステート）**

を組み立てていきます。会話は自動で保存（永続化）され、Node.js や Cloudflare Workers、GitHub Actions などにデプロイできます。

## エージェント = 関数

左のエディタのコードを見てください。Flue のエージェントは **ただの関数** です。

| 書いているもの | 意味 |
| --- | --- |
| `'use agent'` | このファイルがエージェントを定義している、という目印 |
| `export function Assistant()` | エージェント本体。名前（`Assistant`）が会話の保存キーにもなる |
| `useModel('anthropic/claude-haiku-4-5')` | 使う LLM の宣言（必須） |
| `return '...'` | エージェントへの指示（システムプロンプト） |

## 動かしてみよう

右下の入力欄にメッセージを書いて **▶ 実行** を押してください（`Ctrl+Enter` でも実行できます）。

このアプリは裏側で **本物の Flue ランタイム**（`@flue/runtime`）を使ってあなたのコードを実行しています。やっていることはターミナルで次のコマンドを打つのと同じです。

```bash
npx flue run src/agents/assistant.ts --id hello-1 --message "こんにちは！"
```

> 💡 API キーが無い場合は **モックLLM** が応答します。モックLLMは「本物のLLMの代わりに、決まったルールで返事をする偽物のモデル」です。文章は賢くありませんが、Flue のランタイム（フックの実行、ツール呼び出し、会話の保存）はすべて本物なので、仕組みを学ぶには十分です。

## 「モデルに送られた内容」を見てみよう

実行結果の **🔍 モデルへの入力** を開くと、LLM に実際に送られたシステムプロンプト・会話履歴・ツール一覧が見られます。

あなたが `return` した文字列の後ろに、Flue が自動で `## Available Agents` や日付などを付け足していることに気づくはずです。また、何もしていないのに `task` というツールが 1 つあります。これはサブエージェントに仕事を任せるための組み込みツールです（レッスン 7 で使います）。

## やってみよう

1. `return` する文字列を「あなたは関西弁で話す猫です。」などに変えて実行し、🔍 でシステムプロンプトが変わったことを確認する
2. `useModel(...)` の行をコメントアウトして実行し、どんなエラーになるか見る（**useModel は必須**）
3. 関数の中に `console.log('render!')` を書いて実行し、ログ欄に出ることを確認する
